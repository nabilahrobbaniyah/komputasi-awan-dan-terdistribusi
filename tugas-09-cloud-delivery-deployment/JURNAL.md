# Jurnal Proses — Tugas 9

## Diskusi deployment model
- Opsi yang dipertimbangkan dan kenapa akhirnya memilih salah satu: Mempertimbangkan Public Cloud, Private Cloud, Hybrid Cloud, dan Community Cloud. Public Cloud memiliki skalabilitas tinggi, tetapi kurang sesuai untuk menyimpan seluruh data kependudukan yang sangat rahasia. Private Cloud memiliki kontrol dan keamanan lebih tinggi, tetapi membutuhkan pengelolaan kapasitas yang baik saat terjadi lonjakan akses. Community Cloud dapat digunakan bersama instansi tertentu, tetapi Hybrid Cloud dinilai lebih fleksibel. Akhirnya memilih Hybrid Cloud dengan Private Cloud untuk penyimpanan data sensitif dan Public Cloud untuk komponen non-sensitif agar keamanan dan skalabilitas dapat terpenuhi.

## Diskusi service model per komponen
- Database inti data kependudukan menggunakan IaaS karena membutuhkan kontrol terhadap infrastruktur, keamanan, dan penyimpanan data.

- Backend API dan aplikasi layanan menggunakan PaaS agar pengembangan dan deployment aplikasi lebih mudah serta mendukung skalabilitas.

- Layanan pendukung seperti email dan kolaborasi internal dapat menggunakan SaaS karena tersedia dalam bentuk aplikasi siap pakai.
